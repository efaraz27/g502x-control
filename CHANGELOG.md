# Changelog

## 0.5.0

- Redesigned desktop UI with neutral surfaces, compact navigation, clear control groups and restrained color.
- DPI sliders alongside exact numeric entry; denser profile and button editors.
- Original smooth mouse illustration shared by lighting previews and the button map, with legible numbered callouts.
- Aligned settings rows, responsive lighting controls, and updated application/tray icons.
- Read-only rendering and scaled hit-target regression tests; refreshed guide and screenshots.

## 0.4.0

- Live device readings, automatic reconnection and protected profile drafts/open editors.
- Settings for update intervals, native low-battery alerts and a configurable threshold.
- Optional background monitor with a native tray menu and per-user launch at login.
- Persistent alert deduplication, charging suppression, hysteresis and retry/cooldown limits.
- Reopen the existing window from the tray; quit the monitor without losing startup preferences.
- Monitor lifecycle CLI, notification test, and Windows/Linux upgrade handling and Windows uninstall cleanup.

## 0.3.0

- Native Windows/macOS HID backends; Windows/macOS hardware support is experimental.
- Linux x86-64/ARM64 packages, Windows setup/portable ZIP, Intel and Apple Silicon Mac DMGs.
- Checksum-verified Linux installer and automated multi-platform release builds.
- Platform-specific backup paths, cross-platform locking, and native Mac/Windows file dialogs.
- Public documentation, issue templates, contributing guide, and native application icons.

## 0.2.0

- Graphite-and-lime interface, bundled typography, visual button editor, profile tabs, lighting previews, persistent save controls and Linux file picker.

## 0.1.0

- Initial native Rust GUI/CLI for G502 X Plus on Linux.
- USB/LIGHTSPEED, onboard profiles, bindings, live settings, lighting and full-memory backup/restore.
